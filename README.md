# 💠 TOP Agnet 巔峰自主進化戰略終端 (Windows 版)

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Platform: Windows](https://img.shields.io/badge/Platform-Windows-0078d4.svg)](https://www.microsoft.com/windows)

**TOP Agnet** 是一款基於 OMEGA 內核的高階 AI 自主執行平台，專為追求極致效率與數位版圖擴張的「主控官」設計。它不僅僅是一個對話機器人，而是一個具備「上帝之眼」視覺、實時戰術投影、以及自主演化能力的數位幕僚。

---

## 🚀 核心功能 (Core Features)

- **🧠 OMEGA 核心執行器**：具備強大的任務拆解與原子步驟執行力，拒絕空談，唯物實踐。
- **👁️ 上帝之眼 (God's Eye)**：實時監控 AI 的思維邏輯、工具調用與底層 Shell 指令執行過程。
- **📡 戰術投影 HUD**：獨立的感知擴展視窗，可即時渲染網頁快照、數據圖表、甚至是 AI 自主編寫的小遊戲。
- **🧪 自主演化協議 (Self-Evolution)**：當現有工具不足時，AI 具備編寫 Python 程式碼並將其注入武器庫的能力。
- **💰 戰術計費系統**：內建 Token 消耗統計與報表產出功能，支援包月或計費用戶管理。
- **🌐 多模態感知**：支援瀏覽器全自動交互、螢幕錄製、影片/圖像情報解析。

## 📦 安裝指南 (Setup Instructions)

本專案已針對 Windows 11/10 進行完美適配，具備自動化環境部署能力。

### 1. 前置需求
- **Python 3.10+** (請確保安裝時勾選了 "Add Python to PATH")
- **FFmpeg** (推薦安裝，用於螢幕錄影功能)

### 2. 快速啟動
1. 下載本專案並解壓縮。
2. 雙擊執行目錄下的 **`launch_windows.bat`**。
3. 系統將自動執行以下動作：
   - 偵測 Python 環境。
   - 建立獨立的虛擬環境 (`venv`)。
   - 自動安裝所有依賴庫 (`pip install`)。
   - 配置 Playwright 瀏覽器引擎。
   - 啟動指揮中心 GUI。
